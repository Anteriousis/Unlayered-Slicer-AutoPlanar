Privacy and printer connections
Stealth Mode
This disables all cloud features, including cloud profile syncing. Users who prefer to work entirely offline can enable this option.
Note: When Stealth Mode is enabled, your user profiles will not be backed up to the cloud.
Bambu Lab printers
The Bambu Lab network plug-in is required for wireless communication with Bambu Lab 3D printers: sending prints over Wi-Fi or LAN and seeing the printer's status and camera.
It is made by Bambu Lab, not Unlayered, and is downloaded when you press Finish. It works with Stealth Mode on. Not using a Bambu Lab printer? Untick it - you can install it later from Preferences.
