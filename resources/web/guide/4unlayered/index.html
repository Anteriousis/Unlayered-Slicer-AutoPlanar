Online features and printer connections
Stealth Mode
Stealth Mode turns off the slicer's optional online features. The check for new versions of Unlayered Slicer still runs, and printers on your own network keep working.
Bambu Lab printers
The Bambu Lab network plug-in is required for wireless communication with Bambu Lab 3D printers: sending prints over Wi-Fi or LAN and seeing the printer's status and camera.
It is made by Bambu Lab, not Unlayered, and is downloaded when you press Finish. It works with Stealth Mode on. Using a Bambu Lab printer? Tick the box - you can also install it later from Preferences.
