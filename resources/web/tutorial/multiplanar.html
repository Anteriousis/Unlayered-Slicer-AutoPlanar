Multiplanar Printing

Unlayered Slicer — printing one object in several build directions, without splitting it.

On a 5-axis printer the bed can tilt under the nozzle, so different parts of one object can be printed in different directions — an overhanging arm can be built along its own axis, with no support at all. In Unlayered Slicer you describe this with cut planes: non-destructive planes stored on the object. The object is never split in your project; the printable segments, their orientations, and their print order are all derived at slice time and stay editable.

1  Quick start

  1. In Prepare, select the object and open the Cut Planes tool in the left toolbar.
  2. Position the plane with the grabbers — drag to move it along its normal, rotate it with the rings. The coloured chunk preview shows the segments you would get.
  3. Click Add cut plane. The plane is recorded in the list; the gizmo plane stays where it is so you can place the next one.
  4. When asked, switch the print sequence to By group — multiplanar printing requires it (you can also set it later in Process → Others).
  5. Slice. Each segment is printed in its own orientation; the G-code preview shows the tool-axis changes between segments.
Requirements. The printer profile must have non-planar printing enabled (Printer settings → Non-planar). The Unlayered 5-axis profiles ship with it on. Print sequence must be By group.

2  How segments are derived

The planes partition the object. The piece resting on the bed is the root and prints flat, like any normal print. Every other segment sits on exactly one plane — its base plane — and is printed along that plane's normal, on top of the segment across the plane. Arrows on each plane in the 3D view show that direction.

___________ | arm ⟋ | plane 2 → the arm builds along plane 2's normal |___⟋⟍______| | tower | plane 1 → the tower builds along plane 1's normal ___|___________|___ | root | printed flat on the bed, first |_________________|
  • Chain order is geometric. A segment always prints after the segment it sits on — root first, then outward. You cannot break a physical dependency by reordering planes.
  • Sibling order follows your plane list, in reverse. When two segments sit on the same parent, the one from the first plane in the list prints last. Use the arrows in the plane list to reorder.
  • Build direction override. Normally a segment builds along its base plane's normal. To print it in a different direction without moving the plane, select the plane and use the B/C angle fields in the panel (reset restores tracking the plane).

A plane that does not actually split the object is listed but produces no cut.

4  Pipe Cut

For a bent pipe, duct or tube, the Pipe Cut tool places the planes for you. It finds the centreline of the bore and cuts the part into short chunks along it, so each chunk prints square to the pipe. It is for hollow, tube-shaped parts only — a solid or boxy model (a Benchy, a bracket) gets nothing useful from it.

  1. Open the Pipe Cut tool. The centreline is found automatically; edit it if needed — move, delete, or connect nodes.
  2. Click Cut along pipe: one cut plane is added per centreline step (at the step midpoint, facing along the pipe), and you land in the Cut Planes tool with the full list ready to review and edit.
  3. Prefer manual control? Use Step to walk the proposed cuts one by one and Cut here to add only the planes you want.
The object is not split — skeleton cutting authors the same editable plane list as the Cut Planes tool. At most 64 planes per object are supported.

5  Safety checks

  • Hotend collision check. After slicing, the hotend is modelled as a cone (default 90°, 40 mm — Printer settings → Non-planar) and the whole toolpath is checked against everything printed earlier. A collision blocks the print with a message naming the chunks and G-code lines — re-orient the segment, add clearance, or shorten the cone to match your actual hotend.
  • Thin segments. If any derived segment would be thinner than the first layer, the feature turns itself off for that object and the panel tells you why. This includes two nearly-coplanar planes leaving a sliver between them.
  • Duplicate planes (the same plane added twice, either facing) are ignored — the first one wins.

6  Troubleshooting

SymptomCause / fix
Object slices as one flat pieceFeature disabled, no plane splits the mesh, or a segment is thinner than the first layer — the Cut Planes panel shows the reason.
"Requires By group" messageSet Process → Others → Print sequence to By group.
Slice refused with a hotend collisionRead the message: it names the two chunks and where they meet. Re-orient, add clearance, or adjust the cone in Printer settings → Non-planar.
